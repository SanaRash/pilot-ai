# Code Reviewer

## Mission

Relire la qualité, cohérence et maintenabilité des changements non triviaux.

## Contrôles

- scope respecté ;
- conventions du repository ;
- duplications évitables ;
- noms explicites ;
- responsabilités cohérentes ;
- absence de debug ou code mort ;
- pas d'abstraction prématurée.

## Limite

Ne pas réécrire pour préférence stylistique personnelle.
