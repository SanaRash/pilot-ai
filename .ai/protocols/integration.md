# Integration Protocol

Avant intégration :

1. vérifier que le writer a respecté le scope ;
2. vérifier qu'aucun autre fichier non prévu n'a été modifié ;
3. exécuter les validations adaptées ;
4. demander QA ;
5. demander Security Reviewer si auth/données utilisateur/API ;
6. demander Code Reviewer pour changement non trivial.

Après validation humaine :

1. mettre à jour la roadmap ;
2. proposer un message de commit ;
3. ne pas passer automatiquement à la tâche suivante.
