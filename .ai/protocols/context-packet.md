# Context Packet

Chaque délégation doit transmettre uniquement le contexte nécessaire.

## Minimum

```text
TASK:
ROADMAP_ID:
TYPE:
COMPLEXITY:
GOAL:
ACCEPTANCE_CRITERIA:
FILES_TO_INSPECT:
FILES_ALLOWED_TO_MODIFY:
OUT_OF_SCOPE:
KNOWN_CONSTRAINTS:
VALIDATIONS_REQUIRED:
```

Éviter de charger toute la documentation si la tâche est locale.
