# Skill — Create Controller

Avant :
- chercher un contrôleur proche ;
- vérifier la convention de routes ;
- vérifier `security.yaml`.

Commande possible :
```bash
php bin/console make:controller NomController
```

Après :
- supprimer le code de démonstration inutile ;
- garder le contrôleur fin ;
- vérifier la route avec `debug:router`.
