# Workflow — Security Fix

1. Security Reviewer décrit le risque.
2. Requirement Analyst clarifie le comportement autorisé.
3. Symfony Developer corrige.
4. Security Reviewer revalide.
5. QA vérifie les scénarios de rôles.
6. Code Reviewer.
7. Validation humaine.

Aucun changement de sécurité n'est déclaré terminé avec un veto actif.
