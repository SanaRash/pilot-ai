# Workflow — Feature

1. Orchestrator identifie la tâche de roadmap.
2. Requirement Analyst produit les critères d'acceptation.
3. Orchestrator inspecte le repository.
4. Symfony Developer et/ou Frontend Developer implémentent.
5. Database Expert intervient si Doctrine change.
6. QA valide le comportement.
7. Security Reviewer intervient si rôles, données utilisateur, formulaires sensibles ou API.
8. Code Reviewer relit si non trivial.
9. Orchestrator présente le résultat.
10. Validation humaine.
11. Documentation met à jour la roadmap.
12. Proposition de commit.
