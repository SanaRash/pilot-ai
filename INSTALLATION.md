# Installation de l'orchestrateur V2 dans Pilot AI

Copier dans la racine du projet `~/projects/pilot-ai` :

- `AGENTS.md`
- `.ai/`
- `ROADMAP/`
- `PROMPT_ORCHESTRATEUR.txt`

Si l'ancien dossier `agent/` existe, le conserver temporairement jusqu'à vérification puis le supprimer ou l'archiver après validation de la V2.

## Vérification

```bash
ls -la
ls -la .ai
ls -la ROADMAP
git status
```

La première tâche attendue par l'orchestrateur est :

`TASK-3.4 — Afficher le détail d'un ticket côté technicien`.
